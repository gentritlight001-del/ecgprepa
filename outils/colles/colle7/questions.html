1L'intégrale de Gauss

Convergence. La fonction \(t \mapsto e^{-t^2/2}\) est continue et paire sur \(\mathbb{R}\) : il suffit d'étudier \(\int_0^{+\infty} e^{-t^2/2}\,\mathrm{d}t\). Sur \([0, 1]\), la fonction est continue sur un segment. En \(+\infty\), par croissances comparées, \(t^2 e^{-t^2/2} \to 0\), donc \(e^{-t^2/2} = o\!\left(\frac{1}{t^2}\right)\) ; comme \(\int_1^{+\infty} \frac{\mathrm{d}t}{t^2}\) converge (Riemann), \(\int_1^{+\infty} e^{-t^2/2}\,\mathrm{d}t\) converge. Par parité, \(\int_{-\infty}^{0} e^{-t^2/2}\,\mathrm{d}t\) converge aussi.

Valeur (admise). \[\int_{-\infty}^{+\infty} e^{-t^2/2}\,\mathrm{d}t = \sqrt{2\pi}, \qquad \text{donc} \qquad \int_0^{+\infty} e^{-t^2/2}\,\mathrm{d}t = \frac{\sqrt{2\pi}}{2}.\]

2La fonction Gamma

Définition. Pour tout \(x > 0\), l'intégrale \(\displaystyle\int_0^{+\infty} t^{x-1} e^{-t}\,\mathrm{d}t\) converge, et on pose \[\Gamma(x) = \int_0^{+\infty} t^{x-1} e^{-t}\,\mathrm{d}t.\]

Relation fonctionnelle. Pour tout \(x > 0\), \(\Gamma(x + 1) = x\,\Gamma(x)\).

Valeurs entières. \(\Gamma(1) = 1\) et, pour tout \(n \in \mathbb{N}^*\), \(\Gamma(n) = (n - 1)!\).

Décalage d'indice : \(\Gamma(n) = (n - 1)!\), pas \(n!\). Par exemple \(\Gamma(2) = 1\) et \(\Gamma(3) = 2\).

3Exemples de produits scalaires (exemples page 2)

Produits scalaires usuels (sans justification) :

  • sur \(\mathbb{R}^n\) : \(\langle x, y \rangle = \displaystyle\sum_{i=1}^{n} x_i y_i\) pour \(x = (x_1, \dots, x_n)\) et \(y = (y_1, \dots, y_n)\) ;
  • sur \(\MM_{n,1}(\mathbb{R})\) : \(\langle X, Y \rangle = {}^t\!X\,Y = \displaystyle\sum_{i=1}^{n} x_i y_i\) ;
  • sur \(\MM_n(\mathbb{R})\) : \(\langle A, B \rangle = \tr({}^t\!A\,B) = \displaystyle\sum_{i=1}^{n} \sum_{j=1}^{n} a_{i,j}\, b_{i,j}\) ;
  • sur \(\mathscr{C}^0([a, b], \mathbb{R})\), avec \(a < b\) : \(\langle f, g \rangle = \displaystyle\int_a^b f(t)\,g(t)\,\mathrm{d}t\).
Sur \(\mathscr{C}^0([a, b], \mathbb{R})\), il faut \(a < b\) et des fonctions continues : c'est ce qui donne le caractère défini (\(\langle f, f \rangle = 0 \Rightarrow f = 0\)).

4Inégalité de Cauchy-Schwarz ; inégalité triangulaire (Prop. 2, 3)

Soit \(E\) un espace vectoriel muni d'un produit scalaire \(\langle \cdot, \cdot \rangle\) et de la norme associée \(\|x\| = \sqrt{\langle x, x \rangle}\).

Cauchy-Schwarz. Pour tous \(x, y \in E\) : \[|\langle x, y \rangle| \leqslant \|x\|\,\|y\| \qquad \big(\text{soit } \langle x, y \rangle^2 \leqslant \langle x, x \rangle \langle y, y \rangle\big).\]

  • Égalité avec la valeur absolue : \(|\langle x, y \rangle| = \|x\|\,\|y\| \iff\) la famille \((x, y)\) est liée.
  • Égalité sans la valeur absolue : \(\langle x, y \rangle = \|x\|\,\|y\| \iff x = 0_E\) ou il existe \(\lambda \geqslant 0\) tel que \(y = \lambda x\) (vecteurs positivement liés).

Inégalité triangulaire. Pour tous \(x, y \in E\), \(\|x + y\| \leqslant \|x\| + \|y\|\), avec égalité si et seulement si \(x = 0_E\) ou il existe \(\lambda \geqslant 0\) tel que \(y = \lambda x\).

5Théorème de Pythagore (Prop. 4)

Théorème. Pour tous \(x, y \in E\) : \(x \perp y \iff \|x + y\|^2 = \|x\|^2 + \|y\|^2\).

Généralisation. Si \(x_1, \dots, x_n\) sont deux à deux orthogonaux, alors \[\Big\| \sum_{i=1}^{n} x_i \Big\|^2 = \sum_{i=1}^{n} \|x_i\|^2.\]

Pour \(n \geqslant 3\), la réciproque est fausse : l'égalité des carrés des normes ne garantit pas que les vecteurs soient deux à deux orthogonaux.

6Coordonnées dans une base orthonormée (Prop. 8, point 1)

Soient \(E\) un espace euclidien et \((e_1, \dots, e_n)\) une base orthonormée de \(E\). Pour tout \(x \in E\) : \[x = \sum_{i=1}^{n} \langle x, e_i \rangle\, e_i.\] Autrement dit, la \(i\)-ème coordonnée de \(x\) dans cette base est \(\langle x, e_i \rangle\).

Cette formule n'est vraie que dans une base orthonormée.
