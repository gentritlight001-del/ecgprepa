1Diagonaliser · les valeurs propres

Étape 1 : trouver Sp(A)

La méthode : trois outils
Triangulaire : lire la diagonale.
Polynôme annulateur \(Q\) : \(\mathrm{Sp}(A) \subset\) racines de \(Q\).
Rang : \(\lambda \in \mathrm{Sp}(A) \iff \mathrm{rg}(A - \lambda I) < n\).
Exemple
\(A = \begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}\), \(\quad A^2 = \begin{pmatrix} 5 & 4 \\ 4 & 5 \end{pmatrix}\)
On vérifie : \(A^2 - 2A - 3I = 0\).
\(Q = X^2 - 2X - 3 = (X - 3)(X + 1)\)
\(\mathrm{Sp}(A) \subset \{3, -1\}\)
Puis vérifier que chaque racine est bien valeur propre.
1Diagonaliser · conclure

Étape 2 : les sous-espaces propres

\((A - 3I)X = 0\) : \(x = y\), donc \(E_3 = \mathrm{Vect}\big((1, 1)\big)\)
\((A + I)X = 0\) : \(x = -y\), donc \(E_{-1} = \mathrm{Vect}\big((1, -1)\big)\)
\(\dim E_3 + \dim E_{-1} = 1 + 1 = 2 = n\)
\(A\) est diagonalisable
\(P = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}\) (vecteurs propres en colonnes)
\(D = \begin{pmatrix} 3 & 0 \\ 0 & -1 \end{pmatrix}\) (même ordre)
\(A = P D P^{-1}\)
\(A^n = P \begin{pmatrix} 3^n & 0 \\ 0 & (-1)^n \end{pmatrix} P^{-1}\)
1Diagonaliser · le piège

Une seule valeur propre ? Attention

\(A = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}\) : triangulaire, \(\mathrm{Sp}(A) = \{1\}\).
Si \(A\) était diagonalisable : \(D = I\), donc \(A = P\,I\,P^{-1} = I\).
Or \(A \neq I\) :
\(A\) n'est pas diagonalisable
À retenir
Une seule valeur propre \(\lambda\) et \(A \neq \lambda I\) \(\Rightarrow\) pas diagonalisable.
À l'inverse
\({}^t\!A = A\) (symétrique réelle) \(\Rightarrow\) diagonalisable. Ex. : \(\begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}\).
2Changement de base, trace

Passer d'une base à l'autre

\(P_{\mathcal B, \mathcal B'}\) : les nouveaux vecteurs, en colonnes, dans l'ancienne base.
\(\mathcal B' = \big((1,1), (1,-1)\big)\) : \(P = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}\)
\(X' = \begin{pmatrix} 2 \\ 1 \end{pmatrix}\) donne \(X = PX' = \begin{pmatrix} 3 \\ 1 \end{pmatrix}\)
Endomorphisme : \(A' = P^{-1} A P\).
Trace
Somme des coefficients diagonaux ; la même pour deux matrices semblables.
\(\mathrm{tr}(A) = 1 + 1 = 2\) et \(\mathrm{tr}(D) = 3 + (-1) = 2\)
Vérifie tes valeurs propres
3Produit scalaire

Les 4 points à vérifier

\(\displaystyle \langle f, g \rangle = \int_0^1 f(t)\,g(t)\,\mathrm{d}t\) sur \(\mathscr C^0([0,1])\)
1. Symétrique\(\int fg = \int gf\)
2. Linéaire à gauchelinéarité de l'intégrale ; avec 1 : bilinéaire
3. Positive\(\int_0^1 f^2 \geqslant 0\) car \(f^2 \geqslant 0\)
4. Définie\(\int_0^1 f^2 = 0\), \(f^2\) continue et positive \(\Rightarrow f^2 = 0\)
\(f = 0\) : c'est un produit scalaire
3Produit scalaire · deux outils

Cauchy-Schwarz et bases orthonormées

\(|\langle x, y \rangle| \leqslant \|x\|\,\|y\|\)
Exemple, avec \(g = 1\) :
\(\displaystyle \left(\int_0^1 f\right)^2 \leqslant \int_0^1 f^2 \times \underbrace{\int_0^1 1^2}_{=\,1} = \int_0^1 f^2\)
Base orthonormée \((e_1, \dots, e_n)\)
\(x = \sum \langle x, e_i \rangle\, e_i\)
\(\|x\|^2 = \sum \langle x, e_i \rangle^2\)
3Produit scalaire · Gram-Schmidt

Fabriquer une base orthonormée

\(u_1 = (1, 1)\), \(\ u_2 = (1, 0)\)
\(e_1 = \dfrac{u_1}{\|u_1\|} = \dfrac{1}{\sqrt2}(1, 1)\)
\(v_2 = u_2 - \langle u_2, e_1 \rangle\, e_1\), avec \(\langle u_2, e_1 \rangle = \frac{1}{\sqrt2}\)
\(v_2 = \left(\frac12, -\frac12\right) \perp e_1\)
\(e_2 = \dfrac{v_2}{\|v_2\|} = \dfrac{1}{\sqrt2}(1, -1)\)
4Intégrales impropres

Converge ou pas ?

La méthode
1. Repérer les bornes à problème.
2. Fonction positive : comparer à une référence (comparaison, équivalent, \(o\)).
3. Signe quelconque : \(\int |f|\) converge.
Exemple
\(\displaystyle \int_1^{+\infty} \frac{\mathrm{d}t}{t^2 + t}\)
Continue sur \([1, +\infty[\) : seul problème en \(+\infty\).
\(f(t) \geqslant 0\) et \(f(t) \underset{+\infty}{\sim} \dfrac{1}{t^2}\)
Riemann : \(\int_1^{+\infty} \frac{\mathrm{d}t}{t^2}\) converge \((2 > 1)\).
L'intégrale converge
4Intégrales impropres · les réflexes

Multiplier par \(t^2\), puis Gamma

En \(+\infty\) : si \(t^2 f(t) \to 0\), alors \(\int_1^{+\infty} f\) converge.
Exemple : \(f(t) = t^3 e^{-t}\)
\(t^2 f(t) = t^5 e^{-t} \to 0\) (croissances comparées)
\(f(t) = o\!\left(\frac{1}{t^2}\right)\) : converge.
\(\displaystyle \int_0^{+\infty} t^3 e^{-t}\,\mathrm{d}t = \Gamma(4)\)
\(\Gamma(4) = 3! = 6\)
\(\Gamma(n) = (n-1)!\), pas \(n!\)
Gauss : \(\displaystyle \int_0^{+\infty} e^{-t^2/2}\,\mathrm{d}t = \frac{\sqrt{2\pi}}{2}\)
5Suites \(u_{n+1} = f(u_n)\)

Bien définie, puis monotone

\(u_0 = 1\), \(\ u_{n+1} = \sqrt{u_n + 2} = f(u_n)\)
1. Si \(x \in [0, 2]\), \(f(x) \in [\sqrt2, 2] \subset [0, 2]\)
par récurrence, \(u_n \in [0, 2]\) pour tout \(n\).
2. \(g(x) = f(x) - x\) :
\(g\) décroît et \(g(2) = 0\), donc \(g \geqslant 0\) sur \([0, 2]\).
\(u_{n+1} - u_n = g(u_n) \geqslant 0\) : croissante.
5Suites · la limite

Converge, et vers quoi ?

3. Croissante et majorée par 2 : converge (limite monotone).
4. \(f\) continue : \(\ell = \sqrt{\ell + 2}\)
\(\ell^2 - \ell - 2 = 0 \iff \ell \in \{2, -1\}\)
Or \(\ell \geqslant 0\) :
\(u_n \to 2\)
Le programme Python
from math import sqrt

def suite(n):
    u = 1              # u_0
    for k in range(n):
        u = sqrt(u + 2)
    return u
6Développements limités

Les DL en 0, pour une limite

À connaître
\(e^x = 1 + x + \frac{x^2}{2} + o(x^2)\)
\(\ln(1+x) = x - \frac{x^2}{2} + o(x^2)\)
\((1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2}x^2 + o(x^2)\)
\(\frac{1}{1-x} = 1 + x + x^2 + o(x^2)\)
Exemple
\(\displaystyle \lim_{x \to 0} \frac{e^x - 1 - x}{x^2}\)
\(e^x - 1 - x = \frac{x^2}{2} + o(x^2)\)
\(\dfrac{e^x - 1 - x}{x^2} = \dfrac12 + o(1) \to \dfrac12\)
Équivalent : \(\ln(1 + 3x) \sim 3x\), donc \(\frac{\ln(1+3x)}{x} \to 3\)
7Convexité

Au-dessus des tangentes

\(f'' \geqslant 0\) sur \(I\) \(\Rightarrow f\) convexe.
Convexe \(\Rightarrow f(x) \geqslant f(a) + f'(a)(x - a)\).
Exemple : \(f = \exp\).
\(f'' = \exp > 0\) : convexe.
Tangente en 0 : \(y = 1 + x\).
\(e^x \geqslant 1 + x\) pour tout \(x\)
Sujet 2025, problème II.2a : \(1 - x \leqslant e^{-x}\).
8Séries

Comparer, ou télescoper

Riemann : \(\sum \frac{1}{n^\alpha}\) converge \(\iff \alpha > 1\)
Géométrique : \(\sum q^n\) converge \(\iff |q| < 1\)
Exemple : \(\frac{1}{n^2 + 1} \geqslant 0\)
\(\frac{1}{n^2+1} \sim \frac{1}{n^2}\) : la série converge.
Série télescopique
\(\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}\)
\(\displaystyle \sum_{k=1}^{n} \frac{1}{k(k+1)} = 1 - \frac{1}{n+1} \to 1\)
Converge, de somme 1
\(\sum (v_k - v_{k+1})\) converge \(\iff (v_n)\) converge.
9DL à l'ordre 3

Le calcul du problème 2025

\(\ln(1+x) = x - \frac{x^2}{2} + \frac{x^3}{3} + o(x^3)\)
\(\left(n + \frac12\right)\ln\left(1 + \frac1n\right) - 1\), avec \(x = \frac1n\)
\(n \times\) : \(1 - \frac{1}{2n} + \frac{1}{3n^2} + o\!\left(\frac{1}{n^2}\right)\)
\(\frac12 \times\) : \(\frac{1}{2n} - \frac{1}{4n^2} + o\!\left(\frac{1}{n^2}\right)\)
On additionne, on retire 1 : les \(\frac{1}{2n}\) se compensent.
\(\left(\frac13 - \frac14\right)\frac{1}{n^2} = \frac{1}{12n^2} + o\!\left(\frac{1}{n^2}\right)\)
10Polynômes

Bases et matrice dans \(\mathbb R_n[x]\)

\(\dim \mathbb R_n[x] = n + 1\)
Échelonnée en degré \(\Rightarrow\) base.
Ex. : \(\left(1,\ x,\ \frac{x(x-1)}{2}\right)\), degrés 0, 1, 2 : base de \(\mathbb R_2[x]\).
\(B = I + N\), \(N^3 = 0\) : \(B^{-1} = I - N + N^2\)
\(b : P \mapsto P(x+1)\) sur \(\mathbb R_2[x]\)
\(b(1) = 1\), \(\ b(x) = x + 1\)
\(b(x^2) = x^2 + 2x + 1\) (binôme)
\(B = \begin{pmatrix} 1 & 1 & 1 \\ 0 & 1 & 2 \\ 0 & 0 & 1 \end{pmatrix}\)
C'est la matrice \(A\) de l'exercice 1 !
11Arguments qui reviennent

Compter des racines, commuter

\(f(x) = x^3 - 3x + 1\)
\(f(0) = 1 > 0\), \(\ f(1) = -1 < 0\)
\(f'(x) = 3x^2 - 3 < 0\) sur \(]0, 1[\)
Une seule racine dans \(]0, 1[\) (TVI)
\(n\) valeurs propres distinctes en taille \(n\) \(\Rightarrow\) diagonalisable.
\(D = \begin{pmatrix} 1 & 0 \\ 0 & 2 \end{pmatrix}\), \(\ M = \begin{pmatrix} a & b \\ c & d \end{pmatrix}\)
\(DM = \begin{pmatrix} a & b \\ 2c & 2d \end{pmatrix}\), \(\ MD = \begin{pmatrix} a & 2b \\ c & 2d \end{pmatrix}\)
\(b = 2b\) et \(2c = c\) : \(b = c = 0\).
\(M\) est diagonale
12Techniques d'intégrales

IPP et changement de variable

IPP, toujours sur un segment
\(\displaystyle \int_0^A t\,e^{-t}\,\mathrm{d}t\) : \(u = t\), \(v' = e^{-t}\)
\(= \big[-t e^{-t}\big]_0^A + \displaystyle\int_0^A e^{-t}\,\mathrm{d}t = -Ae^{-A} + 1 - e^{-A}\)
\(A \to +\infty\) : \(\to 1\)
\(\int_0^{+\infty} t e^{-t}\,\mathrm{d}t = 1 = \Gamma(2)\)
Changement de variable \(u = \sqrt n\, t\)
\(\mathrm{d}t = \frac{\mathrm{d}u}{\sqrt n}\), borne \(1 \to \sqrt n\) :
\(\displaystyle \int_0^1 e^{-nt^2}\,\mathrm{d}t = \frac{1}{\sqrt n}\int_0^{\sqrt n} e^{-u^2}\,\mathrm{d}u\)
\(\leqslant \dfrac{1}{\sqrt n}\cdot\dfrac{\sqrt\pi}{2} \to 0\)
13Dichotomie en Python

Approcher \(\sqrt 2\) en coupant en deux

def f(x):
    return x**2 - 2

def dicho(epsilon):
    a = 1
    b = 2
    while b - a > epsilon:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
    return (a + b) / 2
Signes contraires : racine à gauche, \(b = m\).
Sinon, à droite : \(a = m\).
