Un produit scalaire

\(\displaystyle \varphi(P, Q) = \int_0^{+\infty} P(t)\,Q(t)\,e^{-t}\,\mathrm{d}t\)
sur \(\mathbb{R}[x]\), l'espace des polynômes
L'énoncé
Montrer que \(\displaystyle \varphi : (P, Q) \mapsto \int_0^{+\infty} P(t)\,Q(t)\,e^{-t}\,\mathrm{d}t\) est un produit scalaire sur \(\mathbb{R}[x]\).
La feuille de route : cinq vérifications
1Bien définiel'intégrale converge
2Symétrique\(\varphi(P, Q) = \varphi(Q, P)\)
3Bilinéairelinéaire à droite et à gauche
4Positive\(\varphi(P, P) \geqslant 0\)
5Définie\(\varphi(P, P) = 0 \Rightarrow P = 0\)
Cours · exemple 6, page 2
1Bien définie

D'abord : l'intégrale converge-t-elle ?

\(PQ\) est un polynôme : \(\displaystyle P(t)\,Q(t) = \sum_{k=0}^{m} c_k\, t^k\).
Exercice 3 · la fonction Γ
\(\displaystyle \int_0^{+\infty} t^k e^{-t}\,\mathrm{d}t = \Gamma(k+1) = k!\) converge
Par linéarité, \(\varphi(P, Q)\) converge et vaut \(\displaystyle \sum_{k=0}^{m} c_k\, k!\)
\(\varphi(P, Q)\) est bien un réel
2Symétrie

Le produit de deux réels commute

\(\displaystyle \varphi(P, Q) = \int_0^{+\infty} \htmlClass{hl hA}{P(t)\,Q(t)}\,e^{-t}\,\mathrm{d}t = \int_0^{+\infty} \htmlClass{hl hB}{Q(t)\,P(t)}\,e^{-t}\,\mathrm{d}t = \varphi(Q, P)\)
\(\varphi\) est symétrique
3Bilinéarité

Linéaire à droite, puis la symétrie

Soient \(P, Q, R \in \mathbb{R}[x]\) et \(\lambda \in \mathbb{R}\).
\(\displaystyle \varphi(P, \lambda Q + R) = \int_0^{+\infty} P(t)\big(\lambda Q(t) + R(t)\big)\,e^{-t}\,\mathrm{d}t\)
\(\displaystyle \phantom{\varphi(P, \lambda Q + R)} = \htmlClass{hl hL}{\lambda \int_0^{+\infty} P(t)\,Q(t)\,e^{-t}\,\mathrm{d}t + \int_0^{+\infty} P(t)\,R(t)\,e^{-t}\,\mathrm{d}t}\)
linéarité de l'intégrale : les deux intégrales convergent (étape 1)
\(\displaystyle \phantom{\varphi(P, \lambda Q + R)} = \lambda\,\varphi(P, Q) + \varphi(P, R)\)
Linéaire à droite, donc à gauche par symétrie : bilinéaire
4Positivité

Un carré ne descend jamais sous l'axe

\(\displaystyle \varphi(P, P) = \int_0^{+\infty} P(t)^2\, e^{-t}\,\mathrm{d}t\)
\(P(t)^2 \geqslant 0\) et \(e^{-t} > 0\) : l'intégrande est positif.
Une intégrale (convergente) d'une fonction positive est positive.
\(\varphi(P, P) \geqslant 0\)
5Caractère défini

Si φ(P, P) = 0 : passer par un segment

Pour tout \(A > 0\) :
\(\displaystyle 0 \leqslant \int_0^{A} P(t)^2 e^{-t}\,\mathrm{d}t \leqslant \varphi(P, P) = 0\)
Théorème · sur un segment
Une fonction continue, positive et d'intégrale nulle sur \([0, A]\) est nulle sur \([0, A]\).
Donc \(P(t)^2 e^{-t} = 0\), et comme \(e^{-t} > 0\) :
\(P(t) = 0\) pour tout \(t \in [0, A]\)
5Caractère défini

Une infinité de racines

\(P\) s'annule sur \([0, A]\) pour tout \(A > 0\) : donc sur tout \([0, +\infty[\).
Rappel
Un polynôme non nul de degré \(n\) a au plus \(n\) racines.
\(P\) a une infinité de racines : \(P = 0\)
\(\varphi\) est un produit scalaire sur \(\mathbb{R}[x]\)
Au passage, pour les monômes :
\(\displaystyle \varphi(X^i, X^j) = \int_0^{+\infty} t^{\,i+j} e^{-t}\,\mathrm{d}t = (i + j)!\)
\(\|X\|^2 = \varphi(X, X) = 2\)→ \(\|X\| = \sqrt{2}\)
Pour la colle

Les 4 réflexes à montrer

1
Une intégrale sur \([0, +\infty[\) : vérifier qu'elle converge avant les axiomes.
2
Prouver la linéarité d'un seul côté : la symétrie donne l'autre.
3
« Continue, positive, d'intégrale nulle » ne vaut que sur un segment \([0, A]\).
4
Finir par les racines : une infinité de racines, donc le polynôme est nul.
