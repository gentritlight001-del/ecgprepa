L'Hypothèse

1
Fondamentaux
Qu'est-ce qu'une hypothèse ?

Une hypothèse (conditional sentence / if-clause) permet d'exprimer une condition et sa conséquence. Elle se compose de deux propositions : la proposition subordonnée introduite par if (la condition) et la proposition principale (le résultat). Le temps employé dans chaque proposition ne détermine pas un moment littéral, mais le degré de réalité de l'hypothèse : réelle, probable, irréelle au présent ou irréelle au passé.

Contrairement au français, l'anglais n'emploie jamais will ou would après if lorsque if introduit la condition — sauf pour formuler une requête polie (If you would just sign here…).

Règles générales des phrases hypothétiques

1. Deux propositions : if + condition, proposition principale + résultat.

2. L'ordre est libre : If + condition, résultat. ou Résultat if + condition. (pas de virgule dans ce second cas).

3. Jamais de will/would dans la proposition en if (sauf politesse).

4. Le temps de la subordonnée indique le degré de réalité, pas le sens temporel littéral.

5. Unless = if… not (sauf si / à moins que).

2
Vérité générale
Type 0 — Le Réel (Zero Conditional)

Le zero conditional exprime une vérité générale, un fait scientifique, une règle ou une habitude systématique. La condition est toujours vraie, donc le résultat l'est également — aucune incertitude n'est exprimée.

✦ If — Vérité générale
If + present simple , present simple
If you raise interest rates, demand falls.
If the market opens, prices fluctuate immediately.
✦ When — Équivalent systématique
When + present simple , present simple
When inflation rises, purchasing power falls.
When a bond matures, the principal is repaid.
🔬
Loi scientifique ou économique
Exprimer une relation de cause à effet toujours vraie.
If supply exceeds demand, prices drop.
Si l'offre dépasse la demande, les prix baissent.
📋
Règle ou instruction
Donner une règle fixe, un règlement d'entreprise ou une procédure.
If an employee resigns, they must give one month's notice.
Si un employé démissionne, il doit donner un préavis d'un mois.
🔁
Habitude systématique
Décrire une réaction automatique et répétée, y compris algorithmique.
If the stock falls below the threshold, the algorithm sells automatically.
Si l'action passe sous le seuil, l'algorithme vend automatiquement.
💡
If vs When : Dans le zero conditional, if et when sont souvent interchangeables car la condition est systématiquement vraie.
If water freezes ≈ When water freezes — dans les deux cas, le résultat est certain.
3
Futur probable
Type 1 — L'Hypothèse Probable (First Conditional)

Le first conditional exprime une hypothèse réaliste et probable dans le futur. La condition est présentée comme plausible : si elle se réalise, une conséquence précise en découlera.

✦ If — Conséquence certaine
If + present simple , will + base verbale
If the board approves the budget, we will launch the project in March.
If rates rise again, the bank will tighten lending.
✦ If — Conséquence modulée
If + present simple , can / may / should + base verbale
If you finish the report early, you can leave at 4pm.
If sales keep growing, the company may open a second office.
✦ Unless — Condition négative
Unless + present simple , will + base verbale
Unless the client confirms today, we will cancel the contract.
Unless costs fall, margins will keep shrinking.
⚠️
Erreur fréquente : ne jamais utiliser will dans la proposition en if.
❌ If it will rain, we will postpone the meeting.
✔ If it rains, we will postpone the meeting.
4
Irréel présent / futur proche
Type 2 — L'Hypothèse Irréelle au Présent (Second Conditional)

Le second conditional exprime une hypothèse irréelle, imaginaire ou peu probable, au présent ou dans un futur proche. La condition est présentée comme contraire à la situation actuelle.

✦ If — Hypothèse irréelle
If + past simple , would + base verbale
If the company cut prices, it would gain market share.
If I were the CEO, I would restructure the department.
✦ If — Résultat négatif
If + past simple , wouldn't + base verbale
If we lost this client, we wouldn't survive the quarter.
If the currency fell further, exports wouldn't recover.
✦ If — Possibilité irréelle
If + past simple , could / might + base verbale
If we invested more in R&D, we could develop new products.
If the deal fell through, we might reconsider the whole strategy.
✒️
Were pour toutes les personnes : dans un registre soutenu, on emploie were (et non was) à toutes les personnes après if, notamment dans l'expression figée if I were you.
If I were you, I would negotiate a better deal.
5
Irréel passé / regret
Type 3 — L'Hypothèse Irréelle au Passé (Third Conditional)

Le third conditional exprime une hypothèse irréelle concernant le passé : un fait qui ne s'est pas produit et sa conséquence imaginaire. Il sert très souvent à exprimer un regret ou un reproche — fréquent dans les études de cas économiques.

✦ If — Regret / reproche
If + past perfect , would have + participe passé
If the firm had diversified earlier, it would have avoided the crisis.
If she had signed the deal, the merger would have succeeded.
✦ If — Résultat négatif évité
If + past perfect , wouldn't have + participe passé
If they hadn't ignored the warning signs, they wouldn't have lost the contract.
✦ If — Possibilité passée manquée
If + past perfect , could / might have + participe passé
If we had negotiated better terms, we could have saved millions.
🚨
Piège fréquent : ne jamais utiliser would have dans la proposition en if.
❌ If they would have known about the risk…
✔ If they had known about the risk, they would have acted differently.
6
Combinaisons temporelles
Les Conditionnels Mixtes (Mixed Conditionals)

Les conditionnels mixtes combinent deux périodes temporelles différentes : une condition passée avec une conséquence présente, ou une condition présente/permanente avec une conséquence passée. Ils permettent d'analyser des situations réelles et complexes — très fréquents en anglais économique.

Structure
Sens
Exemple
If + past perfect, would + BV
Condition passée → conséquence présente
If the company had invested in tech, it would be more competitive today.
If + past simple, would have + PP
Condition permanente → conséquence passée
If she weren't so risk-averse, she would have accepted the offer.
If + past perfect, would have + PP
Rappel — condition et conséquence passées (type 3)
If they had merged earlier, they would have dominated the market.
🔍
Comment identifier le mélange : repérez le marqueur temporel implicite dans chaque proposition (today, now, at that time) pour déterminer si la condition et la conséquence appartiennent à la même période ou non.

Nuances & connecteurs
Autres Expressions de l'Hypothèse

Au-delà de if, plusieurs connecteurs et expressions permettent de nuancer une hypothèse : condition restrictive, précaution, souhait irréalisable ou préférence.

🌙
Souhait irréalisable (wish / if only)
Wish/if only + past simple (présent) ou + past perfect (passé) pour exprimer un regret ou un souhait.
I wish we had more time before the deadline.
Nous aurions aimé avoir plus de temps avant l'échéance.
⚖️
Préférence (would rather)
Would rather + past simple exprime une préférence concernant l'action d'une autre personne.
I'd rather you didn't share these figures yet.
Je préférerais que vous ne partagiez pas encore ces chiffres.
☂️
Précaution (in case)
In case + present simple anticipe un événement possible, par précaution — à ne pas confondre avec if.
Take a backup file in case the server crashes.
Prenez une copie de sauvegarde au cas où le serveur planterait.
Unless ≠ toujours if… not

Unless the deadline is extended, we will miss the target. (= If the deadline isn't extended…)

Mais unless ne s'utilise pas pour exprimer un regret ou une hypothèse négative complexe — on privilégie alors if… not : If they hadn't reacted, the company wouldn't have survived.

8
Pratique
Exercices
Exercice 1 Identifiez le type d'hypothèse et choisissez la forme correcte
01.
If the merger (goes / will go) through, shareholders will benefit significantly.
→ goes (type 1 — présent simple après if)
02.
If I (was / were) in your position, I would renegotiate the contract.
→ were (type 2 — registre soutenu, toutes personnes)
03.
If the team (had met / met) the deadline, the client wouldn't have cancelled.
→ had met (type 3 — past perfect après if)
04.
Unless profits (improve / will improve), the board will vote to close the branch.
→ improve (unless = if… not, présent simple)
05.
If water (boils / boiled) at 100°C, it turns to steam.
→ boils (type 0 — vérité générale)
06.
If they (had / would have) more capital, they could expand internationally.
→ had (type 2 — past simple après if)
Exercice 2 Transformez chaque situation en phrase hypothétique
01.
The company lost the deal because it didn't lower its price. (type 3)
→ If the company had lowered its price, it wouldn't have lost the deal.
02.
I don't have enough time, so I can't finish the report today. (type 2)
→ If I had enough time, I could finish the report today.
03.
The board doesn't know the real figures, so they aren't worried. (type 2)
→ If the board knew the real figures, they would be worried.
04.
Interest rates are rising rapidly, so the market may crash. (type 1)
→ If interest rates continue to rise rapidly, the market may crash.
05.
She didn't check the contract carefully, so she missed the clause. (type 3)
→ If she had checked the contract carefully, she wouldn't have missed the clause.
06.
We don't invest in training, so productivity stays low. (type 2)
→ If we invested in training, productivity wouldn't stay low.
Exercice 3 Reformulez les phrases avec le connecteur indiqué
01.
If you don't submit the form by Friday, your application will be rejected. → (unless)
→ Unless you submit the form by Friday, your application will be rejected.
02.
I regret that we didn't hire a consultant earlier. → (wish)
→ I wish we had hired a consultant earlier.
03.
You can attend the meeting only if you confirm in advance. → (provided that)
→ You can attend the meeting provided that you confirm in advance.
04.
Bring a printed copy — the projector might fail. → (in case)
→ Bring a printed copy in case the projector fails.
05.
I would prefer if you didn't mention this to the client yet. → (would rather)
→ I'd rather you didn't mention this to the client yet.
06.
The strategy needs to work, or we will need a plan B. → (otherwise)
→ The strategy needs to work; otherwise, we will need a plan B.
