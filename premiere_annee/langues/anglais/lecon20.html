Conditionnel

Si … alors : du fait toujours vrai à l'hypothèse qui ne s'est pas réalisée.

L'essentiel en 3 points

  1. Type 1 : if + présent, will ; jamais will après if.
  2. Type 2 : if + prétérit, would ; If I were you.
  3. Type 3 : if + had + participe, would have + participe.
Fondamentaux
Qu'est-ce que le conditionnel ?

Le conditionnel anglais exprime une action qui dépend d'une condition. On distingue quatre types, selon le degré de probabilité ou de réalité de la situation : du fait toujours vrai (type 0) à l'hypothèse passée qui ne s'est pas réalisée (type 3).

La phrase compte deux propositions : la condition, introduite par if, et la principale, qui donne la conséquence. L'ordre peut s'inverser ; la virgule n'est obligatoire que lorsque if vient en tête.

Structure générale

If + condition, principaleIf it rains, we will cancel the meeting. Principale + if + conditionWe will cancel the meeting if it rains. (sans virgule)

Les quatre types de conditionnel
01
Type 0 : vérité générale
Faits toujours vrais, lois scientifiques ou économiques. Présent + présent.
If demand rises, prices go up. Quand la demande augmente, les prix montent.
02
Type 1 : hypothèse réelle
La condition est possible : on envisage un résultat futur réaliste. Présent + will.
If the deal goes through, we will hire 50 people. Si l'accord aboutit, nous embaucherons 50 personnes.
03
Type 2 : irréel du présent
La condition est contraire à la réalité actuelle, ou improbable. Prétérit + would.
If I had more capital, I would invest in tech. Si j'avais plus de capital, j'investirais dans la tech.
04
Type 3 : irréel du passé
La condition ne s'est pas réalisée : regret, scénario alternatif. Past perfect + would have.
If we had hired earlier, we would have grown faster. Si nous avions embauché plus tôt, nous aurions grandi plus vite.
Type 0
Le conditionnel zéro : vérité générale

Le type 0 exprime des vérités générales, des faits scientifiques ou des habitudes : chaque fois que la condition est remplie, le résultat suit. Ce n'est pas vraiment une hypothèse, mais une relation de cause à effet.

If peut alors être remplacé par when sans changer le sens.

If + présent, présent
If + sujet + présent simple + sujet + présent simple
If you heat water to 100°C, it boils.
If markets crash, investors panic.
When + présent, présent
When + sujet + présent simple + résultat au présent
When demand increases, prices rise.
When the sun sets, it gets dark.
Repère : au type 0, les deux propositions sont au présent simple, sans will ni would : c'est la marque d'une vérité intemporelle.
Type 1
Le conditionnel 1 : hypothèse réelle

Le type 1 exprime une hypothèse réalisable dans le présent ou le futur : la condition est possible, le résultat probable. C'est le conditionnel de la promesse, de la mise en garde et du plan.

Après if, on emploie le présent simple, jamais will, même si le sens est futur.

Affirmatif
If + présent simple + will + base
If the deal goes through, we will hire 50 people.
If she applies, she will get the job.
Négatif
If + présent simple + won't + base
If costs rise, we won't expand.
If he doesn't sign, the deal won't go ahead.
Interrogatif
If + présent simple + will + sujet + base ?
If demand drops, will we cut production?
If she accepts, will you inform the board?
01
Promesse
Si la condition est remplie, celui qui parle s'engage.
If you meet the targets, we will increase your bonus. Si vous atteignez les objectifs, nous augmenterons votre prime.
02
Mise en garde
Annoncer une conséquence négative.
If inflation persists, the central bank will raise rates. Si l'inflation persiste, la banque centrale relèvera ses taux.
03
Plan sous condition
Une décision qui se concrétisera si la condition est remplie.
If the pilot succeeds, we will roll it out globally. Si le projet pilote réussit, nous le déploierons partout.
Erreur classique : jamais de will dans la proposition en if.
If she will come, I will be happy. → If she comes, I will be happy.
Type 2
Le conditionnel 2 : irréel du présent

Le type 2 exprime une hypothèse contraire à la réalité présente, ou une situation imaginaire et peu probable. La proposition en if est au prétérit (le sens reste présent) et la principale au would + base.

On l'emploie pour conseiller, imaginer ou explorer un scénario.

Cas particulier : were

Avec be, la langue soignée emploie were à toutes les personnes : If I were you, I would reconsider. If she were the CEO, the strategy would be different. (was se rencontre à l'oral, mais were est préférable dans une copie.)

Affirmatif
If + prétérit + would + base
If I had more capital, I would invest in tech.
If the market were stable, we would expand.
Négatif
If + prétérit + wouldn't + base
If costs were lower, we wouldn't outsource.
If she knew the truth, she wouldn't agree.
Conseil : If I were you
If I were you + I would + base
If I were you, I would negotiate the terms.
If I were the CFO, I would cut overheads.
01
Situation irréelle
La condition contredit la réalité : on imagine un autre présent.
If the company had no debt, it would be more competitive. Si l'entreprise n'avait pas de dette, elle serait plus compétitive.
02
Conseil
Se mettre à la place de l'autre avec If I were you.
If I were you, I would diversify the portfolio. À ta place, je diversifierais le portefeuille.
03
Scénario peu probable
Envisager une situation possible mais improbable.
If interest rates fell to zero, consumption would soar. Si les taux d'intérêt tombaient à zéro, la consommation s'envolerait.
Would sans if : la condition reste souvent sous-entendue, surtout dans la presse : A public execution would require a waiver (« exigerait une dérogation », sous-entendu : si elle avait lieu). On garde would + base.
Type 3
Le conditionnel 3 : irréel du passé

Le type 3 exprime un regret ou une critique sur le passé : la condition ne s'est pas réalisée, et l'on imagine ce qui se serait passé autrement.

La proposition en if est au past perfect (had + participe passé), la principale au conditionnel passé (would have + participe passé).

Affirmatif
If + had + participe + would have + participe
If we had hired earlier, we would have grown faster.
If she had read the contract, she would have refused.
Négatif
If + hadn't + participe + wouldn't have + participe
If they hadn't borrowed so much, they wouldn't have collapsed.
If we hadn't acted, the loss would have been greater.
Interrogatif
Would + sujet + have + participe + if + had + participe ?
Would they have invested if they had known the risks?
Would the firm have survived if it had diversified?
01
Regret
La situation ne s'est pas produite : on imagine après coup ce qui aurait pu arriver.
If we had invested in renewables earlier, we would have led the market. Si nous avions investi plus tôt dans les renouvelables, nous aurions dominé le marché.
02
Analyse après coup
Juger des décisions passées, comme dans une étude de cas.
If the CEO had restructured the debt, the company would not have gone bankrupt. Si le PDG avait restructuré la dette, l'entreprise n'aurait pas fait faillite.
03
Histoire contrefactuelle
Imaginer une autre issue à un événement réel.
If Lehman Brothers had been rescued, the 2008 crisis might have been less severe. Si Lehman Brothers avait été sauvée, la crise de 2008 aurait peut-être été moins grave.
Nuances avancées
Variantes et alternatives à if

D'autres conjonctions et tournures expriment la condition sans if. Elles sont fréquentes à l'écrit soutenu et enrichissent une copie.

01
Unless : sauf si
Unless = if … not. La condition est négative, le verbe qui suit reste affirmatif.
Unless inflation falls, rates will remain high. À moins que l'inflation ne baisse, les taux resteront élevés.
02
Provided (that), as long as
Condition nécessaire : « à condition que », souvent dans un registre soutenu.
Provided that all parties agree, the merger will proceed. À condition que toutes les parties acceptent, la fusion aura lieu.
03
Should + sujet (soutenu)
Dans les textes officiels, should en tête remplace if, avec inversion.
Should the client fail to pay, penalties will apply. Si le client ne paie pas, des pénalités s'appliqueront.
04
Had + sujet (type 3 soutenu)
Au type 3, had peut ouvrir la phrase à la place de if.
Had the board acted sooner, the crisis would have been averted. Si le conseil avait agi plus tôt, la crise aurait été évitée.
05
Supposing, on condition that
Explorer un scénario ou poser une condition stricte.
Supposing growth slowed, what would our plan be? À supposer que la croissance ralentisse, quel serait notre plan ?

In case ≠ if : in case exprime une précaution. Take an umbrella in case it rains : prends un parapluie au cas où il pleuvrait (qu'il pleuve ou non). If it rains, take a taxi : seulement s'il pleut.
Pratique
Exercices
Exercice 1 Quel est le type de conditionnel ? (0, 1, 2 ou 3)
01.
If you add sugar to coffee, it tastes sweeter.
→ type 0 (vérité générale)
02.
If the firm raises capital, it will launch the product next year.
→ type 1 (hypothèse réelle)
03.
If I were the CEO, I would restructure the entire supply chain.
→ type 2 (irréel du présent)
04.
If they had diversified earlier, they would not have lost so much during the crisis.
→ type 3 (irréel du passé)
05.
If demand drops, prices fall.
→ type 0 (loi économique)
06.
If she had known about the merger, she would have bought the shares.
→ type 3 (regret)
