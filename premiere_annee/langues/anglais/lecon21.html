Hypothèse

Imaginer, regretter, poser une condition : les nuances de l'hypothèse.

L'essentiel en 3 points

  1. Le temps après if dit le degré de réalité, pas le moment.
  2. Mixte : If I had studied, I would be rich now.
  3. wish + prétérit (présent), wish + had + participe (passé).
Fondamentaux
Qu'est-ce qu'une hypothèse ?

Une phrase hypothétique (conditional sentence) exprime une condition et sa conséquence, en deux propositions : la subordonnée en if et la principale. Le temps employé n'indique pas un moment précis mais le degré de réalité de l'hypothèse : réelle, probable, irréelle au présent ou irréelle au passé.

Contrairement au français, l'anglais n'emploie jamais will ni would dans la proposition en if, sauf dans une demande polie (If you would just sign here…). La leçon 20 présente les quatre types ; cette leçon les approfondit et ajoute les cas mixtes et les autres façons d'exprimer l'hypothèse.

Les règles générales

Deux propositionsif + condition, puis la principale (le résultat) Ordre libreIf + condition, résultat. ou Résultat if + condition. (sans virgule dans ce second cas) Pas de will / woulddans la proposition en if (sauf politesse) Le temps = la réalitéplus on recule dans le passé, plus l'hypothèse s'éloigne du réel Unless= if … not : sauf si, à moins que

Vérité générale
Type 0 : le réel

Le zero conditional exprime une vérité générale, un fait scientifique, une règle ou une réaction systématique : la condition entraîne toujours le résultat.

If : vérité générale
If + présent simple + présent simple
If you raise interest rates, demand falls.
If supply exceeds demand, prices drop.
When : équivalent
When + présent simple + présent simple
When inflation rises, purchasing power falls.
When a bond matures, the principal is repaid.
01
Loi économique
Une relation de cause à effet toujours vraie.
If supply exceeds demand, prices drop. Si l'offre dépasse la demande, les prix baissent.
02
Règle
Une règle fixe, un règlement, une procédure.
If an employee resigns, they must give one month's notice. Un salarié qui démissionne doit respecter un préavis d'un mois.
03
Réaction automatique
Une réaction systématique, y compris celle d'un programme.
If the share price falls below the threshold, the algorithm sells. Si le cours passe sous le seuil, l'algorithme vend.
Futur probable
Type 1 : l'hypothèse probable

Le first conditional exprime une hypothèse réaliste : la condition est plausible, et si elle se réalise, une conséquence précise suivra.

If : conséquence attendue
If + présent simple + will + base
If the board approves the budget, we will launch in March.
If rates rise again, banks will tighten lending.
If : conséquence nuancée
If + présent simple + can / may / should + base
If you finish early, you can leave at 4.
If sales keep growing, the firm may open a second office.
Unless : condition négative
Unless + présent simple + will + base
Unless the client confirms today, we will cancel.
Unless costs fall, margins will keep shrinking.
Erreur fréquente : jamais de will après if.
If it will rain, we will postpone the meeting. → If it rains, we will postpone the meeting.
Irréel du présent
Type 2 : l'hypothèse irréelle au présent

Le second conditional exprime une hypothèse irréelle, imaginaire ou peu probable, au présent ou dans un futur proche : la condition contredit la situation actuelle.

If : hypothèse irréelle
If + prétérit + would + base
If the company cut prices, it would gain market share.
If I were the CEO, I would restructure the department.
If : résultat négatif
If + prétérit + wouldn't + base
If we lost this client, we wouldn't survive the quarter.
If the currency fell further, exports wouldn't recover.
If : possibilité
If + prétérit + could / might + base
If we invested more in R&D, we could develop new products.
If the deal fell through, we might rethink the strategy.
Were à toutes les personnes : dans la langue soignée, were remplace was après if, en particulier dans If I were you, I would negotiate a better deal.
Irréel du passé
Type 3 : l'hypothèse irréelle au passé

Le third conditional porte sur le passé : un fait qui ne s'est pas produit et sa conséquence imaginée. Il sert souvent à exprimer un regret ou un reproche, notamment dans les études de cas.

If : regret, reproche
If + past perfect + would have + participe
If the firm had diversified earlier, it would have avoided the crisis.
If she had signed the deal, the merger would have succeeded.
If : conséquence évitée
If + past perfect + wouldn't have + participe
If they hadn't ignored the warnings, they wouldn't have lost the contract.
If : occasion manquée
If + past perfect + could / might have + participe
If we had negotiated better terms, we could have saved millions.
Piège fréquent : jamais de would have dans la proposition en if.
If they would have known about the risk… → If they had known about the risk, they would have acted differently.
Combinaisons de temps
Les conditionnels mixtes

Les conditionnels mixtes associent deux époques : une condition passée et une conséquence présente, ou une condition permanente et une conséquence passée. Ils permettent d'analyser finement une situation réelle.

Structure
Sens
Exemple
If + past perfect, would + base
condition passée → conséquence présente
If the company had invested in tech, it would be more competitive today.
If + prétérit, would have + participe
trait permanent → conséquence passée
If she weren't so cautious, she would have accepted the offer.
If + past perfect, would have + participe
rappel : type 3, tout au passé
If they had merged earlier, they would have dominated the market.
Repérer le mélange : cherchez le repère de temps de chaque proposition (today, now, at that time, last year) pour savoir si la condition et la conséquence appartiennent à la même époque.
Nuances et connecteurs
Les autres façons d'exprimer l'hypothèse

Au-delà de if, plusieurs mots et tournures nuancent l'hypothèse : condition restrictive, précaution, souhait irréalisable ou préférence.

unlessà moins que
provided thatà condition que
as long astant que, pourvu que
on condition thatà condition que (soutenu)
in caseau cas où (précaution)
otherwisesinon
even ifmême si
supposingà supposer que
01
Wish, if only : souhait
wish + prétérit pour le présent, + past perfect pour le passé : un souhait ou un regret.
I wish we had more time. I wish we had started earlier. J'aimerais que nous ayons plus de temps. Si seulement nous avions commencé plus tôt.
02
Would rather : préférence
would rather + sujet + prétérit : ce qu'on préférerait que quelqu'un d'autre fasse.
I'd rather you didn't share these figures yet. Je préférerais que vous ne diffusiez pas encore ces chiffres.
03
In case : précaution
in case + présent : on prend ses précautions, que l'événement arrive ou non.
Take a backup file in case the server crashes. Prenez une copie de sauvegarde au cas où le serveur tomberait en panne.
Unless n'est pas toujours if … not

Unless the deadline is extended, we will miss the target. (= If the deadline isn't extended…)
Pour un regret ou une hypothèse irréelle au passé, on garde if … not : If they hadn't reacted, the company wouldn't have survived.

Pratique
Exercices
Exercice 1 Choisissez la forme correcte
01.
If the merger (goes / will go) through, shareholders will benefit.
→ goes (type 1 : présent après if)
02.
If I (was / were) in your position, I would renegotiate the contract.
→ were (type 2, registre soigné)
03.
If the team (had met / met) the deadline, the client wouldn't have cancelled.
→ had met (type 3)
04.
Unless profits (improve / will improve), the board will close the branch.
→ improve (présent après unless)
05.
If water (boils / boiled), it turns to steam.
→ boils (type 0)
06.
If they (had / would have) more capital, they could expand abroad.
→ had (type 2 : prétérit après if)
Exercice 2 Transformez la situation en phrase hypothétique
01.
The company lost the deal because it didn't lower its price. (type 3)
→ If the company had lowered its price, it wouldn't have lost the deal.
02.
I don't have enough time, so I can't finish the report today. (type 2)
→ If I had enough time, I could finish the report today.
03.
The board doesn't know the real figures, so they aren't worried. (type 2)
→ If the board knew the real figures, they would be worried.
04.
Interest rates are rising fast; the market may crash. (type 1)
→ If interest rates keep rising fast, the market may crash.
05.
She didn't check the contract carefully, so she missed the clause. (type 3)
→ If she had checked the contract carefully, she wouldn't have missed the clause.
06.
We don't invest in training, so productivity stays low. (type 2)
→ If we invested in training, productivity would improve.
Exercice 3 Reformulez avec le mot indiqué
01.
If you don't submit the form by Friday, your application will be rejected. → unless
→ Unless you submit the form by Friday, your application will be rejected.
02.
I regret that we didn't hire a consultant earlier. → wish
→ I wish we had hired a consultant earlier.
03.
You can attend the meeting only if you confirm in advance. → provided that
→ You can attend the meeting provided that you confirm in advance.
04.
Bring a printed copy: the projector might fail. → in case
→ Bring a printed copy in case the projector fails.
05.
I would prefer you not to mention this to the client yet. → would rather
→ I'd rather you didn't mention this to the client yet.
06.
The strategy must work, or we will need a plan B. → otherwise
→ The strategy must work; otherwise, we will need a plan B.
