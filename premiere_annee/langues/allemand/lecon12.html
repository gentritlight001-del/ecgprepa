Les prépositions

Prépositions + accusatif, datif, génitif, et prépositions mixtes.

L'essentiel en 3 points

  1. für, ohne, durch + acc. ; mit, bei, zu + datif ; wegen, trotz + gén.
  2. Mixtes : wohin ? → accusatif, wo ? → datif.
  3. nach Berlin, in die Schweiz, zum Arzt.
Fondamentaux

Chaque préposition impose un cas au groupe qui la suit (leçon 5) : il faut l'apprendre avec son cas. Quatre groupes :

Contractions : im, am, zum, zur, vom, beim, ins, ans (leçon 5). Les prépositions imposées par un verbe (warten auf, sich freuen über) : leçon 13.

Les sept à retenir : aus, bei, mit, nach, seit, von, zu. Gegenüber se place souvent après un pronom : mir gegenüber.
Citer une source dans la presse : laut + datif (« selon ») devant le nom : laut dem Bericht, laut AFP ; zufolge + datif, après le nom : dem Bericht zufolge ; unter Berufung auf + accusatif (« en citant ») : unter Berufung auf Diplomaten.

Dans la presse : zugunsten (en faveur de), angesichts (face à), infolge (à la suite de) + génitif : angesichts der Hitze.
Prépositions mixtes
Accusatif ou datif ?

Neuf prépositions prennent l'accusatif ou le datif selon le sens : mouvement vers un lieu (wohin ?) → accusatif ; action dans un lieu (wo ?) → datif.

Sens non spatial : an, in, vor prennent le datif pour le temps (am Montag, im Juli, vor zwei Jahren). Über + accusatif = « plus de » ou « à propos de » : über ein Jahr, über das Projekt sprechen.

Exercices
Exercice 1 Complétez avec l'article
01.
Ich arbeite für Chef.
→ den (für + accusatif)
02.
Er fährt mit Zug.
→ dem (mit + datif)
03.
Wegen Wetters bleibe ich hier.
→ des (wegen + génitif)
04.
Sie wohnt bei Eltern.
→ den (datif pluriel)
05.
Ohne Hilfe geht es nicht.
→ die (ohne + accusatif)
06.
Während Sitzung schweigt er.
→ der (génitif féminin)
