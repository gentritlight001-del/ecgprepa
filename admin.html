Base de données partagée Les comptes sont enregistrés dans ta base Supabase : tu vois ici toutes les inscriptions, quel que soit l'appareil utilisé, et les blocages ou fermetures de session s'appliquent à distance. Valider chaque nouveau compte

Les nouvelles inscriptions restent « en attente » et n'ont accès à rien tant que tu ne les as pas approuvées depuis l'onglet Comptes.

Inscriptions ouvertes

Quand c'est désactivé, la création de compte est refusée par la base elle-même, pas seulement par la page de connexion.

Exporter

Télécharge un fichier JSON contenant les comptes, les sessions, le journal et les réglages. Les mots de passe ne sont jamais exportés : ils restent chiffrés dans Supabase.
