La fonction racine carrée

Ce qu'est la racine carrée d'un nombre, comment calculer avec, et comment se comporte la fonction \(x \mapsto \sqrt{x}\).

Tape tes réponses dans les cases, puis « Vérifier ». Le bouton √ écrit une racine.
1. La racine carrée d'un nombre 2. Les règles de calcul 3. Pas de racine au dénominateur 4. La fonction racine carrée 5. Équations et inéquations 6. Comparer \(x\), \(x^2\) et \(\sqrt{x}\)
L'essentiel

\(\sqrt{a}\) est le nombre positif dont le carré vaut \(a\). Il n'existe que si \(a \geq 0\).

Une racine se coupe sur un produit ou un quotient, jamais sur une somme : \(\sqrt{9+16} \neq \sqrt{9}+\sqrt{16}\).

La fonction \(x \mapsto \sqrt{x}\) est définie sur \([0\,;+\infty[\) et strictement croissante.

1La racine carrée d'un nombre

Définition

Soit \(a\) un nombre réel positif ou nul. La racine carrée de \(a\), notée \(\sqrt{a}\), est l'unique nombre positif ou nul dont le carré est égal à \(a\).

\[\sqrt{a} \geq 0 \qquad\text{et}\qquad \left(\sqrt{a}\right)^2 = a\]
Exemple

\(\sqrt{49} = 7\) car \(7 \geq 0\) et \(7^2 = 49\). De même, \(\sqrt{0} = 0\), \(\sqrt{1} = 1\) et \(\sqrt{0{,}25} = 0{,}5\) car \(0{,}5^2 = 0{,}25\).

Certaines racines ne « tombent pas juste » : \(\sqrt{2} \approx 1{,}414\). On garde alors l'écriture \(\sqrt{2}\), qui est la valeur exacte.

À retenir

\(\sqrt{-4}\) n'existe pas : aucun nombre réel n'a un carré négatif. On ne prend la racine carrée que d'un nombre positif ou nul.

Propriété

Pour tout nombre réel \(a\) :

\[\sqrt{a^2} = \begin{cases} a & \text{si } a \geq 0 \\ -a & \text{si } a < 0 \end{cases}\]
Piège à éviter

\(\sqrt{(-5)^2}\) ne vaut pas \(-5\) : \((-5)^2 = 25\) et \(\sqrt{25} = 5\). Une racine carrée n'est jamais négative.

2Les règles de calcul

Théorème

Pour tous nombres réels \(a \geq 0\) et \(b \geq 0\) :

\[\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}\]

et, si de plus \(b > 0\) :

\[\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}\]
Démonstration

Le nombre \(\sqrt{a} \times \sqrt{b}\) est positif, et son carré vaut \(\left(\sqrt{a}\right)^2 \times \left(\sqrt{b}\right)^2 = a \times b\). C'est donc le nombre positif dont le carré est \(ab\) : c'est \(\sqrt{ab}\). Même raisonnement pour le quotient.

Piège à éviter

Pour une somme, c'est faux : \(\sqrt{9+16} = \sqrt{25} = 5\), alors que \(\sqrt{9}+\sqrt{16} = 3+4 = 7\).

Méthode · écrire sous la forme \(a\sqrt{b}\)

On écrit le nombre sous la racine comme le produit d'un carré parfait (le plus grand possible) par un autre entier, puis on « sort » la racine du carré.

\[\sqrt{50} = \sqrt{25 \times 2} = \sqrt{25} \times \sqrt{2} = 5\sqrt{2}\]

Les carrés parfaits à connaître : \(4,\ 9,\ 16,\ 25,\ 36,\ 49,\ 64,\ 81,\ 100\).

Exemple

\(\sqrt{12} = \sqrt{4 \times 3} = 2\sqrt{3}\).

Pour additionner des racines, on les écrit toutes avec le même nombre sous la racine : \(\sqrt{18}+\sqrt{8} = 3\sqrt{2}+2\sqrt{2} = 5\sqrt{2}\), comme \(3\) pommes \(+\ 2\) pommes \(=5\) pommes.

3Pas de racine au dénominateur

Méthode

Pour \(b > 0\), on multiplie le numérateur et le dénominateur par \(\sqrt{b}\) :

\[\dfrac{a}{\sqrt{b}} = \dfrac{a \times \sqrt{b}}{\sqrt{b} \times \sqrt{b}} = \dfrac{a\sqrt{b}}{b}\]

La valeur ne change pas, puisqu'on multiplie par \(\dfrac{\sqrt{b}}{\sqrt{b}} = 1\). Mais le résultat est plus simple à lire et à comparer.

Exemple

\(\dfrac{6}{\sqrt{3}} = \dfrac{6 \times \sqrt{3}}{\sqrt{3} \times \sqrt{3}} = \dfrac{6\sqrt{3}}{3} = 2\sqrt{3}\).

À toi de jouer Partie 3

Exercice 5. Écris chaque nombre sans racine au dénominateur, sous la forme la plus simple.

\(\dfrac{10}{\sqrt{5}} =\)
\(\dfrac{1}{\sqrt{2}} =\)
\(\sqrt{\dfrac{3}{4}} =\)
Voir la correction

\(\dfrac{10}{\sqrt{5}} = \dfrac{10\sqrt{5}}{5} = 2\sqrt{5}\).

\(\dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{\sqrt{2} \times \sqrt{2}} = \dfrac{\sqrt{2}}{2}\).

\(\sqrt{\dfrac{3}{4}} = \dfrac{\sqrt{3}}{\sqrt{4}} = \dfrac{\sqrt{3}}{2}\) : ici, le dénominateur \(\sqrt{4} = 2\) n'a déjà plus de racine.

4La fonction racine carrée

Définition

La fonction racine carrée est la fonction \(f\) définie sur \([0\,;+\infty[\) par \(f(x) = \sqrt{x}\).

Tableau de valeurs
\(x\)\(0\)\(0{,}25\)\(1\)\(2\)\(4\)\(9\)
\(\sqrt{x}\)\(0\)\(0{,}5\)\(1\)\(\approx 1{,}41\)\(2\)\(3\)

La courbe part de l'origine et monte de moins en moins vite : pour que \(\sqrt{x}\) passe de \(2\) à \(3\), il faut que \(x\) passe de \(4\) à \(9\).

Théorème

La fonction racine carrée est strictement croissante sur \([0\,;+\infty[\) : pour tous nombres réels \(a\) et \(b\) tels que \(0 \leq a < b\), on a \(\sqrt{a} < \sqrt{b}\).

Démonstration

Soient \(a\) et \(b\) tels que \(0 \leq a < b\). Alors \(b > 0\), donc \(\sqrt{a}+\sqrt{b} > 0\), et on peut écrire :

\[\begin{aligned} \sqrt{b}-\sqrt{a} &= \dfrac{\left(\sqrt{b}-\sqrt{a}\right)\left(\sqrt{b}+\sqrt{a}\right)}{\sqrt{b}+\sqrt{a}} \\ &= \dfrac{b-a}{\sqrt{b}+\sqrt{a}} \end{aligned}\]

Le numérateur \(b-a\) est strictement positif, le dénominateur aussi : donc \(\sqrt{b}-\sqrt{a} > 0\), c'est-à-dire \(\sqrt{a} < \sqrt{b}\).

Exemple · comparer

Deux nombres positifs et leurs racines sont rangés dans le même ordre. Comme \(2{,}5 < 3\), on a \(\sqrt{2{,}5} < \sqrt{3}\).

Pour comparer \(7\) et \(\sqrt{50}\), on écrit \(7 = \sqrt{49}\) : comme \(49 < 50\), on a \(7 < \sqrt{50}\).

5Équations et inéquations

Propriété · l'équation \(\sqrt{x} = k\)
  • Si \(k \geq 0\), l'équation \(\sqrt{x} = k\) a une seule solution : \(x = k^2\).
  • Si \(k < 0\), elle n'a aucune solution.
Exemple

\(\sqrt{x} = 4\) donne \(x = 4^2 = 16\). On vérifie : \(\sqrt{16} = 4\).

\(\sqrt{x} = -2\) n'a pas de solution, car une racine carrée n'est jamais négative.

Propriété · les inéquations

Pour \(k \geq 0\), grâce à la croissance de la fonction racine carrée :

\[\sqrt{x} \leq k \iff 0 \leq x \leq k^2\] \[\sqrt{x} \geq k \iff x \geq k^2\]
Exemple

\(\sqrt{x} < 3 \iff 0 \leq x < 9\) : l'ensemble des solutions est \([0\,;9[\). On n'oublie pas le \(0\) : \(x\) doit être positif pour que \(\sqrt{x}\) existe.

6Comparer \(x\), \(x^2\) et \(\sqrt{x}\)

Propriété
  • Pour \(0 \leq x \leq 1\) : \(x^2 \leq x \leq \sqrt{x}\).
  • Pour \(x \geq 1\) : \(\sqrt{x} \leq x \leq x^2\).
Démonstration

\(x-\sqrt{x} = \sqrt{x}\left(\sqrt{x}-1\right)\). Si \(0 \leq x \leq 1\), alors \(\sqrt{x} \leq 1\) : ce produit est négatif ou nul, donc \(x \leq \sqrt{x}\). Si \(x \geq 1\), il est positif ou nul, donc \(\sqrt{x} \leq x\). On fait de même avec \(x^2-x = x(x-1)\).

Exemple

Pour \(x = 0{,}25\) : \(x^2 = 0{,}0625\) et \(\sqrt{x} = 0{,}5\), donc \(0{,}0625 < 0{,}25 < 0{,}5\) : entre \(0\) et \(1\), c'est la racine la plus grande.

Pour \(x = 4\) : \(\sqrt{4} = 2\) et \(4^2 = 16\), donc \(2 < 4 < 16\) : au-delà de \(1\), c'est le carré le plus grand.
